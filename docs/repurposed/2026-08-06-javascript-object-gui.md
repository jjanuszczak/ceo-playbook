## LinkedIn

### Option 1

JavaScript Object GUI is a project I started thinking about in 2006 and can now finally build properly.

The idea is simple:

- Build browser applications with JavaScript objects.
- Set properties.
- Add controls to containers.
- Wire explicit events.
- Keep state and validation readable.

No HTML-first mental model. No direct DOM plumbing in application code.

This is not a React replacement. It is a narrower bet: internal tools, CRUD-heavy systems, and form-heavy business applications should often feel more like desktop software than page construction.

So what?

AI-assisted coding does not remove the need for product judgment. It lowers the cost of scaffolding enough that smaller, sharper tools become viable again.

### Option 2

AI coding has changed the economics of niche software tools.

In the past, building a small custom UI framework meant carrying too much surface area by hand: runtime, controls, examples, docs, tests, release flow, and roadmap discipline.

Now the scaffolding cost is lower.

But the standard has to stay high:

- Explicit control contracts
- Real examples
- Deterministic tests
- Honest roadmap notes
- Clear pre-release limits

JavaScript Object GUI is my experiment in that direction: an object-first browser UI framework for internal tools and line-of-business applications.

So what?

The opportunity is not to build more vague platforms. It is to build sharper tools with tighter boundaries.

### Option 3

Most frontend work starts from pages.

JavaScript Object GUI starts from applications.

That difference matters when the target is not a public website, but a work surface people use all day:

- Admin consoles
- Opportunity boards
- Planning tools
- Form-heavy workflows
- CRUD systems

JOG uses a desktop-style model: controls, containers, stores, events, validation, dialogs, tabs, grids, and explicit binding.

The browser still renders the DOM. The developer works at the object layer.

So what?

For some internal software, the right abstraction is not another page framework. It is a control system that makes the business workflow easier to reason about.
